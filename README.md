# MyJob Hunter

An AI-powered career productivity assistant designed to help graduates and job seekers organize, manage, and optimize their job search using Artificial Intelligence.

## 📖 Project Overview

MyJob Hunter is a modern AI-powered web application that streamlines the job search process by combining career planning, company research, professional communication, and interview preparation into one platform.

The application addresses common challenges faced by graduates and job seekers, such as managing multiple applications, researching potential employers, meeting deadlines, and communicating professionally with recruiters. By integrating AI-powered features, MyJob Hunter improves productivity and helps users stay organized throughout their career journey.

This project demonstrates practical AI implementation, prompt engineering, real-world problem solving, responsible AI usage, and modern UI/UX design.

## 🚀 Installation and Setup

### Clone the repository

```bash
https://github.com/nqinisiphosethu-png/sethu-myjob-hunter.git
```

### Navigate to the project folder

```bash
cd myjob-hunter
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

## 🤖 Responsible AI Statement

MyJob Hunter uses Artificial Intelligence to support job seekers with planning, company research, interview preparation, and professional communication.

AI-generated responses are intended to assist users and may occasionally contain inaccuracies or outdated information. Users are encouraged to review, verify, and personalize all generated content before submitting job applications, communicating with recruiters, or making important career decisions.

Artificial Intelligence is designed to support human decision-making, not replace it.
